# 🏥 Hospital Emergency & Clinical Analytics Dashboard

An enterprise-grade, multi-page Power BI analytical solution designed to translate complex healthcare data into actionable executive insights, clinical risk alerts, and financial metrics.

## 📊 Project Overview & Features
* **Multi-Page Architecture:** 
  * **Monthly View:** High-level operational activity, daily admission rhythms, and test outcome distributions.
  * **Consolidated View:** Cross-sectional deep dive into financial billing revenue, attending doctor workloads, hospital distributions, and insurance provider matrices.
  * **Detail Insight:** Plain-English executive summaries, clinical findings, and strategic recommendations tailored for leadership review.
* **Design System:** Built using a professional corporate palette (Deep Navy `#0A2540`, Primary Blue `#007AFF`, Alert Red `#FF3B30`, and Soft Gray-Blue `#F4F7FA`), featuring synchronized cross-page filtering and custom UI containers.

---

## 🛠️ Tools & Technologies
* **Microsoft Power BI:** DAX measures (`DISTINCTCOUNTNOBLANK`, percentage calculations), custom tooltips, interactive slicers, and relational data modeling.
* **Microsoft Excel:** Data cleaning, attribute expansion, age grouping, and pivot structuring.
* **Data Source:** Healthcare dataset simulation[cite: 9].

## 🚀 Key Strategic Recommendations
1. **Prioritize High-Risk Diagnostics:** Implement rapid review protocols for the 35%+ abnormal test rate to accelerate patient care cycles.
2. **Optimize Chronic Care:** Establish targeted pathways for high-volume conditions like **Diabetes** and **Hypertension** to reduce readmission frequencies.
3. **Streamline Payer Workflows:** Enhance administrative integration with major insurance partners (Cigna, Blue Cross) to protect operating margins.
